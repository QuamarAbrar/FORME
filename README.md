# FORME

> Considered tools for extraordinary play. Precision in every detail. Nothing in excess.

FORME is a modern e-commerce storefront for minimalist gaming peripherals and desk objects, built with React 19, TypeScript, Vite, and Tailwind CSS v4.

## Features

- **Curated Catalog**: Showcases mechanical keyboards, ultra-lightweight mice, studio audio headsets, controllers, and desk objects.
- **Interactive UI**: Micro-animations, scroll-reveal animations, responsive mobile navigation, and interactive favoriting/swatches.
- **Fast Build & Modern Stack**: Powered by Vite 8 and Tailwind CSS v4 with sub-second HMR and optimized asset bundling.

## Tech Stack

- **Framework**: React 19 + React DOM 19
- **Build Tool**: Vite 8
- **Language**: TypeScript 5.7
- **Styling**: Tailwind CSS v4
- **Formatter**: oxfmt

## Getting Started

### Installation

```bash
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build the application for production:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

### Code Formatting

```bash
npm run format
```
